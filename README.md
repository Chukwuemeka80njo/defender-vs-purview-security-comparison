Overview
This project provides a **clear comparison** between:

- **Microsoft Defender** (Security / Threat Protection)
- **Microsoft Purview** (Data Governance / Compliance)

Focusing on:
- Identification & Authentication (IA)  
- Access Control (AC)

---

Defender vs Purview

Microsoft Defender (Security Layer)
- Detects identity risks and compromised accounts  
- Uses **risk-based access decisions**  
- Protects endpoints, email, and applications  
- Applies session-level controls for cloud apps  

---

Microsoft Purview (Data Governance Layer)
- Enforces **RBAC (Role-Based Access Control)**  
- Applies **Sensitivity Labels & DLP policies**  
- Controls access to sensitive data  
- Supports compliance and data lifecycle management  

---

Key Differences

| Feature | Microsoft Defender | Microsoft Purview |
|--------|------------------|------------------|
| Focus | Threat Protection | Data Governance |
| Access Control | Risk-based | Policy-based |
| IA Role | Detects identity threats | Enforces identity controls |
| Data Protection | Reactive + detection | Preventive + classification |

---

Key Takeaway
- **Defender** → Protects identities from threats  
- **Purview** → Governs how data is accessed and used  

Together, they support a **Zero Trust security model**
